2. Core Architectural Requirements #

A. Real-Time Transport Layer #

  • Protocol: WebSockets for bi-directional streaming with automatic SSE fallback for lightweight clients.
  • Latency Target: Sub-100ms time-to-first-token (TTFT) network handshaking.
  • Connection Management: Distributed Pub/Sub state broker (Redis/NATS) for session handling across horizontally scaled app instances.

B. Multi-Model Gateway & Orchestration #

  • Router: Unified API interface supporting OpenAI, Anthropic, local vLLM instances, and custom fallback models.
  • Resilience: Dynamic retry with exponential backoff, circuit breaking, and semantic response caching.
  • Rate-Limiting: Per-user and per-organization token bucket throttling.

C. Context & Vector Memory Pipeline #

  • Context Hydration: Dynamic hybrid retrieval (Vector + BM25 keyword search) for active user sessions.
  • Memory Tiering: Short-term sliding-window conversation memory backed by fast cache + long-term episodic memory in vector index.

D. Security & Compliance #

  • Authentication: JWT-based OAuth2 / OIDC authentication at gateway edge.
  • Data Privacy: Automatic PII scrubbing prior to LLM payload dispatch; zero-retention data policies where required.
